# MVP 功能範圍

## 首頁：目前持股

首頁是使用者開啟系統後的第一個畫面，包含：

- 全部、台股、美股三種檢視
- 股票代號與名稱
- 持有股數
- 平均成本
- 最新價格與價格更新時間
- 目前市值
- 未實現損益金額與報酬率
- 台股、美股及整體資產摘要

## 後續頁面

1. 交易紀錄：新增買進、賣出、費用與稅金。
2. 每日價格：自動更新失敗時可手動輸入。
3. 資產歷史：保存每日兩次快照並比較資產變化。
4. 設定：更新時間、匯率與行情來源。

## 暫定會計原則

- 持股成本採移動平均成本法。
- 台股以 TWD、美股以 USD 保存原幣資料。
- 費用與稅金記錄於個別交易，不硬編券商費率。
- 是否換算總資產、現金及股息功能於實作前確認。
